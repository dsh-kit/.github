# dsh-kit

A maintainable baseline for DeepSeek Harness plugins.

- [Generator, template and docs](https://github.com/dsh-kit/dsh-kit)
- [dsh-quicknote](https://github.com/dsh-kit/dsh-quicknote) — a real plugin built with the template
- Documentation: [dsh-kit.dev](https://dsh-kit.dev)
- Install (after the first npm release): `pnpm create dsh-kit my-plugin`

The template is TypeScript + React 19 (TSX), with both halves tested, a reproducible build, agent-ready context,
and one command (`pnpm verify`) for the whole check.
